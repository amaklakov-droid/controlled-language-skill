# Code of conduct

This project uses the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html)
as its code of conduct. The full text is on the website of the Contributor
Covenant. This page gives a short summary and tells you how to report a
problem.

## Summary

We want a friendly and safe community for all people. Be respectful and
patient. Give useful feedback about the work, not about the person. Do not
harass, insult, or threaten other people.

The code of conduct applies in all spaces of the project:

- The repository, issues, and pull requests.
- GitHub Discussions.
- Other places where you represent the project.

## Report a problem

If you see or experience unacceptable behavior, report it in one of these
ways:

- Contact the maintainer,
  [@amaklakov-droid](https://github.com/amaklakov-droid).
- Use the **Report content** feature of GitHub. Click the **...** menu of
  the comment, issue, or pull request. Then click **Report content**.

The maintainer reviews each report and keeps the name of the reporter
private. The enforcement guidelines of the Contributor Covenant 2.1 apply.
