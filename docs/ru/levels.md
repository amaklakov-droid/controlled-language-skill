# Уровни

[English](../en/levels.md) · **Русский**

У skill три уровня. Каждый уровень применяет свой набор правил со своей
строгостью. Уровень 1 делает структуру текста понятной. Уровень 2 делает
структуру строгой. Уровень 3 применяет все правила. В английском уровень 3
добавляет ещё и контроль словаря.

Сводка и описания уровней ниже даны для английского — родного языка
подхода. О других языках — в разделе
[Уровни в других языках](#уровни-в-других-языках).

## Как устроены уровни

В skill есть каталог из 39 правил. У каждого правила своя строгость
на каждом уровне:

- **must** (обязательно): skill применяет правило всегда. Отступление —
  нарушение.
- **prefer** (предпочтительно): skill применяет правило, если оно не делает
  текст менее понятным. Отступление — рекомендация.
- **off** (выключено): skill не применяет правило.

Проценты показывают долю обязательных правил. Они приблизительные. Полная
матрица — в
[rules.md](../../controlled-language/references/rules.md#rule-matrix)
(на английском).

## Уровень 1: Light

Уровень 1 делает структуру понятной и сохраняет голос автора. Используйте
его, если нужен более ясный текст с минимумом правок.

На уровне 1 skill:

- пишет инструкции нумерованными шагами в повелительном наклонении;
- ставит каждое условие перед действием;
- использует активный залог в инструкциях;
- держит предложения короче 25 слов (инструкции) и 30 слов (описания);
- убирает идиомы, метафоры, шутки и расплывчатые слова;
- использует один термин для одного понятия;
- пишет предупреждения как команду и риск.

На уровне 1 skill допускает фразовые глаголы, любые формы глагола, формы
на «-ing» и два связанных действия в одном шаге.

## Уровень 2: Standard

Уровень 2 используется по умолчанию. Он применяет все правила структуры и
большую часть правил словаря. Это близко к подходу «80% от ASD-STE100».

На уровне 2 skill также:

- даёт одну инструкцию в предложении;
- держит предложения короче 20 слов (инструкции) и 25 слов (описания);
- использует простые частые слова и одно значение у каждого слова;
- заменяет фразовые глаголы одним глаголом («set up» → «configure»);
- использует «must», «can» и «do not» вместо «should», «may», «might»,
  «could» и «would»;
- использует пассивный залог в описаниях, только если исполнитель действия
  не важен;
- не использует точку с запятой и не пропускает артикли.

На уровне 2 skill предпочитает слова, которые одобряет ASD-STE100. Другие
частые слова допустимы, если в предложении у них только одно значение.

## Уровень 3: Strict

Уровень 3 применяет все правила. Используйте его для процедур безопасности,
регулируемых продуктов и текстов для перевода на много языков.

На уровне 3 skill также делает в английском тексте следующее:

- использует только общие слова, которые одобряет ASD-STE100, в одобренном
  значении и как одобренную часть речи;
- для всех остальных слов использует термины проекта (technical nouns и
  technical verbs);
- использует только простые формы глагола: повелительное наклонение,
  инфинитив, простое настоящее, простое прошедшее, простое будущее время и
  причастие прошедшего времени в роли прилагательного;
- не использует формы на «-ing», кроме терминов;
- использует пассивный залог, только если исполнитель неизвестен;
- использует американскую орфографию.

**О словаре.** Словарь ASD-STE100 принадлежит ASD (Aerospace, Security
and Defence Industries Association of Europe). В проекте его нет.
На уровне 3 skill опирается на знания модели об одобренных словах. Если
skill не уверен, что слово одобрено, он берёт более простое слово. Если
простого слова с тем же смыслом нет, skill выносит слово в список «Words to
verify». Для формальной проверки сверяйте текст
с [официальным стандартом](https://www.asd-ste100.org/).

## Уровни в других языках

Все три уровня работают во всех языках. В каталоге 39 правил:

- **32 универсальных правила** действуют для всех языков, с той же
  строгостью на каждом уровне, что и в английском.
- **7 правил** действуют только для английского. Они касаются английской
  грамматики и словаря ASD-STE100. Например: одобренные слова, формы
  на «-ing», фразовые глаголы, простые формы глагола, артикли.
- **Языковые правила** переносят универсальные правила на грамматику
  конкретного языка. Например, русские правила (`RU1`–`RU9`) убирают
  отглагольные существительные, канцелярит и деепричастные обороты.

| Уровень | Английский | Другие языки |
| --- | --- | --- |
| 1 Light | 19 обязательных правил | Универсальные и языковые правила со строгостью уровня 1 |
| 2 Standard | 34 обязательных правила | Универсальные и языковые правила со строгостью уровня 2 |
| 3 Strict | Все 39 правил и одобренный словарь | Все универсальные и все языковые правила обязательны. Без контроля словаря. |

В ASD-STE100 нет словаря для других языков. Поэтому уровень 3 в других
языках не контролирует словарь. Skill сообщает об этом, когда применяет
уровень 3 к тексту не на английском.

Языковые файлы есть для русского, немецкого, французского и испанского.
Они лежат в
[`controlled-language/references/languages/`](../../controlled-language/references/languages/).
Для других языков skill применяет универсальные правила и обычные
соглашения технического письма на этом языке.

## Выбор уровня

Skill использует первый уровень, который найдёт, в таком порядке:

1. **Запрос**: «Level 3», «strict», «light», «80% of the way to
   ASD-STE100».
2. **Front matter** документа: `controlled-language: 3`.
3. **Правило для пути** (override) в `.controlled-language.yml`.
4. **Уровень по умолчанию** в `.controlled-language.yml`.
5. **Уровень 2**.

Уровень можно изменить и для части документа маркером
`<!-- controlled-language: level 3 -->`. Подробнее —
в [configuration.md](configuration.md).

## Какой уровень использовать

| Текст | Уровень |
| --- | --- |
| Внутренние заметки, черновик, первая чистка старой документации | 1 |
| Блог и обучающие статьи в авторском стиле | 1 |
| Руководства пользователя, справочный центр, README, справочник API | 2 |
| Тексты интерфейса, сообщения об ошибках, release notes | 2 |
| Процедуры установки, обновления и восстановления | 2 или 3 |
| Инструкции по безопасности, необратимые и финансовые операции | 3 |
| Регулируемые продукты (медицина, авиация, промышленность) | 3 |
| Тексты для машинного перевода на много языков | 3 |

В одном проекте можно использовать разные уровни. Например, задайте
уровень 2 по умолчанию и уровень 3 для `docs/safety/**` через override.
