# Controlled Language: agent skill для понятной технической документации на любом языке

[English](../../README.md) · **Русский** · [Другие языки](../LANGUAGES.md)

**Controlled Language** — открытый [Agent Skill](https://agentskills.io).
Он учит AI-агента писать, переписывать и проверять техническую документацию
на контролируемом языке — на английском или на любом другом. Правила
основаны на принципах **ASD-STE100 Simplified Technical English** (STE) —
контролируемого языка авиационных руководств по техническому обслуживанию.
Строгость правил выбираете вы: уровень 1, 2 или 3.

- **Английский** — родной язык подхода. Для него действует полный набор
  правил, а на уровне 3 — ещё и одобренный словарь ASD-STE100.
- **Другие языки** получают те же принципы в форме, которая подходит
  их грамматике. Языковые файлы добавляют правила для русского, немецкого,
  французского и испанского. Носители языков могут добавить новые.

```bash
npx skills add amaklakov-droid/controlled-language-skill
```

Skill работает с Claude, OpenAI Codex, GitHub Copilot, Cursor, Gemini CLI и
другими агентами, которые поддерживают стандарт `SKILL.md`. Для чат-моделей
без поддержки skills используйте [системный промпт](../../prompts/system-prompt.md).

> Проект не связан с ASD (Aerospace, Security and Defence Industries
> Association of Europe) и не одобрен ею. ASD-STE100 — товарный знак ASD.
> Проект не содержит текст стандарта ASD-STE100 и его словарь.
> Подробнее — в разделе [Правовая информация](#правовая-информация).

## Зачем нужен контролируемый язык

Контролируемый язык ограничивает словарь и структуру предложений. Текст
получается однозначным, быстро читается и легко переводится. Его понимают
читатели, которые плохо знают язык. Машинный перевод и LLM обрабатывают такой
текст с меньшим числом ошибок.

Идея skill появилась после
[поста Андрея Карпатого](https://x.com/karpathy/status/2105819303471976479).
Он просит LLM объяснять сложные вещи на ASD-STE100. Иногда он просит текст
«на 80% от ASD-STE100», потому что полный стандарт очень строгий. Этот skill
делает такой подход воспроизводимым: уровень 2 — это и есть «80%».

## Что делает skill

| Режим | Вы даёте | Вы получаете |
| --- | --- | --- |
| Написание (write) | Тему, заметки, код или факты | Новый документ на контролируемом языке |
| Переписывание (rewrite) | Текст или файл | То же содержание на выбранном уровне и заметки |
| Проверка (review) | Текст или файл | Отчёт: номер правила, проблема, исправление |
| Ответы (respond) | «Отвечай на контролируемом языке» | Ответы на контролируемом языке до конца диалога |

Skill меняет только текст. Он сохраняет код, команды, имена файлов, URL,
надписи интерфейса, названия продуктов и цитаты. Он сохраняет термины
вашего проекта: названия компонентов, типов данных и действий.

## Уровни

| | Уровень 1: Light | Уровень 2: Standard | Уровень 3: Strict |
| --- | --- | --- | --- |
| Доля правил | около 50% | около 80% (по умолчанию) | 100% |
| Длина предложения: инструкция / описание | 25 / 30 слов | 20 / 25 слов | 20 / 25 слов |
| Словарь | Свободный, но буквальный и конкретный | Простые частые слова, одно значение у каждого слова | Только общие слова, одобренные ASD-STE100, и термины проекта |
| Грамматика | Активный залог, шаги в повелительном наклонении | Плюс: без фразовых глаголов, без «should» и «may» | Плюс: только простые формы глаголов, без форм на «-ing» |
| Для чего | Внутренние заметки, первая чистка | Руководства пользователя, README, документация API | Процедуры безопасности, регулируемые продукты |

Уровень можно указать в одном из мест:

- в запросе: «перепиши на уровне 3»;
- во front matter документа;
- в конфигурационном файле проекта.

Подробнее — в [levels.md](levels.md).

## Языки

| | Английский | Другие языки |
| --- | --- | --- |
| Правила | Все 39 правил | 32 универсальных правила и правила языкового файла |
| Уровни | 1, 2, 3 | 1, 2, 3 |
| Словарь на уровне 3 | Только общие слова, одобренные ASD-STE100 | Без контроля словаря: одобренного словаря нет |
| Языковые правила | Встроены | [русский](../../controlled-language/references/languages/ru.md), [немецкий](../../controlled-language/references/languages/de.md), [французский](../../controlled-language/references/languages/fr.md), [испанский](../../controlled-language/references/languages/es.md) |

Универсальные правила управляют структурой. Например: длина предложения,
одна инструкция в предложении, условие перед действием, активный залог,
один термин для одного понятия, чёткие предупреждения. Языковые правила
переносят эти идеи на грамматику конкретного языка. Например, русские
правила заменяют «произведите настройку» на «настройте».

Если для языка нет языкового файла, skill применяет универсальные правила
и сообщает, что файла для языка пока нет. Как добавить язык — в
[translating.md](translating.md#языковые-правила-для-skill).

## Быстрый старт

1. Установите skill (см. [Установка](#установка)).
2. Сформулируйте запрос агенту. Например:
   - «Rewrite `docs/install.md` in controlled English, Level 2.»
   - «Проверь README на уровне 3 и дай отчёт.»
   - «Напиши процедуру обновления для этого CLI на контролируемом
     английском.»
   - «Explain how OAuth works, 80% of the way to STE.»
   - «Перепиши инструкцию `docs/ru/setup.md` понятным языком, уровень 3.»
3. Необязательно: добавьте в проект конфигурационный файл. Скопируйте
   [`controlled-language.example.yml`](../../controlled-language/assets/controlled-language.example.yml)
   в корень проекта под именем `.controlled-language.yml`. Впишите в глоссарий
   свои термины.

**Пример (уровень 2).**

Было:

<!-- controlled-language: off -->
> Once you've backed up your wallet, simply navigate to Settings and hit
> Upgrade - the app will then begin downloading the new version.
<!-- controlled-language: on -->

Стало:

> 1. Make a backup of your wallet.
> 2. Open the **Settings** page.
> 3. Click **Upgrade**.
>    The app downloads the new version.

Больше примеров — в папке [examples/](../../examples/).

## Установка

Skill соответствует открытому стандарту [Agent Skills](https://agentskills.io).
Одна и та же папка работает во всех агентах, которые поддерживают
`SKILL.md`.

| Агент | Команда или расположение |
| --- | --- |
| Любой агент (установщик) | `npx skills add amaklakov-droid/controlled-language-skill` |
| Claude Code (плагин) | `/plugin marketplace add amaklakov-droid/controlled-language-skill`, затем `/plugin install controlled-language@controlled-language-skill` |
| Claude.ai, Claude Desktop | Загрузите ZIP-архив папки `controlled-language/` в **Settings → Capabilities → Skills** |
| OpenAI Codex, GitHub Copilot, Cursor, Gemini CLI, OpenCode, Goose | `.agents/skills/controlled-language/` в проекте или глобальная папка skills агента |
| ChatGPT, Gemini, DeepSeek, локальные модели | Вставьте [prompts/system-prompt.md](../../prompts/system-prompt.md) в системный промпт или пользовательские инструкции |

Полная инструкция для каждого агента — в [installation.md](installation.md).

## Скрипт проверки

В skill входит скрипт проверки. Он находит измеримые проблемы: длинные
предложения и абзацы, точки с запятой и слова из списков замен для
английского и для языковых файлов. В английском тексте он также находит
пассивный залог, фразовые глаголы, формы на «-ing» и нечёткие модальные
слова. Язык каждого файла скрипт определяет сам. Нужен только Python 3.8
или новее.

```bash
python3 controlled-language/scripts/check.py --level 2 README.md docs/
```

В непрерывной интеграции (CI) используйте параметр
`--fail-on violation`. Скрипт не понимает смысл текста. Он не заменяет проверку человеком или skill. Подробнее —
в [usage.md](usage.md#скрипт-проверки).

## Участие в проекте

Мы рады любой помощи. Вы можете исправить документацию, добавить язык,
сообщить о плохом результате skill или улучшить скрипт проверки. Прочитайте
[CONTRIBUTING.md](../../CONTRIBUTING.md) (на английском).

**Языки.** Носители языков могут помочь двумя способами:

- перевести документацию;
- написать или проверить языковой файл skill для своего языка.

Для начала откройте
[запрос на язык](https://github.com/amaklakov-droid/controlled-language-skill/issues/new?template=language-request.yml).
Первый черновик делает AI. Затем его проверяют носители языка. После
проверки мы публикуем результат. Подробнее — в [translating.md](translating.md).
