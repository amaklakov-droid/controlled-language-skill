# Languages

This page lists the languages of the project. A language can have two
parts:

- a translation of the documentation;
- a language file of the skill, with the rules for the grammar of the
  language.

English is the source language. The English sources are `README.md` and the
files in `docs/en/`. Each translation is in a language folder:
`docs/<lang>/`. The process is in
[Translate the documentation](en/translating.md).

## Language files of the skill

The skill works with text in any language. English has the full rule set.
A language file adds the rules for one more language. The files are in
[`controlled-language/references/languages/`](../controlled-language/references/languages/).

| Language | Code | File | Status | Reviewed by |
| --- | --- | --- | --- | --- |
| Русский (Russian) | `ru` | [ru.md](../controlled-language/references/languages/ru.md) | reviewed | [@amaklakov-droid](https://github.com/amaklakov-droid) |
| Deutsch (German) | `de` | [de.md](../controlled-language/references/languages/de.md) | draft | — |
| Français (French) | `fr` | [fr.md](../controlled-language/references/languages/fr.md) | draft | — |
| Español (Spanish) | `es` | [es.md](../controlled-language/references/languages/es.md) | draft | — |

A "draft" file did not get a review from a native speaker. To review or to
add a language file, see
[Language rules for the skill](en/translating.md#language-rules-for-the-skill).

The columns show the number of files in each state:

| Column | Meaning |
| --- | --- |
| Reviewed | A native speaker approved the file. The file matches the current English source. |
| Draft | The file matches the current English source. It waits for a native review. |
| Outdated | The English source changed. The file needs an update. |
| Missing | The English source has no translation yet. |
| Invalid | The i18n header is missing or has an error. This column shows only when such files exist. |
| Reviewed by | The reviewers in the i18n headers of the files. |

The tool `tools/i18n_status.py` makes the table. Do not edit the table by
hand. To update it, run this command:

```bash
python3 tools/i18n_status.py table
```

## Request a language

To request a new language, open the form
[Request a language](https://github.com/amaklakov-droid/controlled-language-skill/issues/new?template=language-request.yml).
The maintainer accepts a language when at least one native speaker agrees to
review the translation or the language file.

## Reviewers

Reviewers are native speakers who review translations and language files.
GitHub asks them to review each pull request for their language. The file `.github/CODEOWNERS`
controls these requests.

| Language | Code | Language maintainer | Reviewers |
| --- | --- | --- | --- |
| Русский (Russian) | `ru` | [@amaklakov-droid](https://github.com/amaklakov-droid) (maintainer) | [@amaklakov-droid](https://github.com/amaklakov-droid) |

To volunteer as a reviewer, open the form
[Volunteer as a native-speaker reviewer](https://github.com/amaklakov-droid/controlled-language-skill/issues/new?template=reviewer-signup.yml).
