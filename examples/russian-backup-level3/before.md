# Резервное копирование и восстановление базы данных

Данный раздел является руководством по осуществлению резервного копирования базы данных сервиса, а также восстановлению данных из резервной копии в случае возникновения сбоя.

## Создание резервной копии

Для создания резервной копии администратору необходимо подключиться к серверу по SSH, после чего, перейдя в каталог `/opt/app`, произвести запуск скрипта `backup.sh`. Следует учитывать, что в процессе выполнения резервного копирования производительность сервиса может быть снижена, в связи с чем рекомендуется осуществлять данную операцию в период минимальной нагрузки.

Резервная копия сохраняется в каталог `/var/backups/app`, имя файла формируется автоматически на основании текущей даты.

## Восстановление из резервной копии

Восстановление данных производится посредством запуска скрипта `restore.sh` с указанием имени файла резервной копии в качестве параметра:

```bash
sudo ./restore.sh app-2026-10-01.dump
```

Обращаем внимание, что при восстановлении все текущие данные базы будут безвозвратно удалены и заменены данными из резервной копии, поэтому перед выполнением данной операции рекомендуется убедиться в корректности выбранного файла.
