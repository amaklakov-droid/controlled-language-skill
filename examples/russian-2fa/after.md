# Как включить двухфакторную аутентификацию

Чтобы защитить учётную запись, включите двухфакторную аутентификацию (2FA).
Для этого нужно приложение-аутентификатор, например Google Authenticator или
Яндекс Ключ.

1. Откройте раздел **Профиль**.
2. Выберите вкладку **Безопасность**.
3. Нажмите **Подключить 2FA**.
   На экране появится QR-код.
4. Отсканируйте QR-код с помощью приложения-аутентификатора.
   Приложение-аутентификатор покажет шестизначный код.
5. Введите этот шестизначный код в поле для кода.

> **ВНИМАНИЕ:** Сохраните резервные коды в надёжном месте. Если вы потеряете
> доступ к приложению-аутентификатору, восстановить доступ к учётной записи
> может быть трудно.
